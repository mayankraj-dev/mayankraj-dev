## Security-Minded Development Checklist

Habits I apply across every project, not just "security" ones:

- Keep credentials and tokens out of source code (`.env`, secret managers)
- Treat all external input as untrusted
- Add rate limiting and timeouts to anything hitting an external service
- Fail gracefully — plan for the API/service being down
- Keep operational logs without over-collecting user data
- Test edge cases, not just the happy path
